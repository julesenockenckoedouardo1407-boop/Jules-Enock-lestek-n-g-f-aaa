# Jules Enock Lestekè — Jwèt Mab

Jeu de billes tactile basé sur la version HTML originale.

**Créé par Jules Enock.**

## Inclus
- Jeu tactile hors ligne.
- PWA installable.
- Écran **À propos** avec « Créé par Jules Enock ».
- Vraie icône d'application.
- Workflow GitHub Actions pour générer un APK Android.

## Générer l'APK avec un téléphone
1. Crée un dépôt GitHub vide, par exemple `jules-enock-lesteke`.
2. Importe tous les fichiers de ce projet dans le dépôt.
3. Ouvre **Actions** sur GitHub.
4. Ouvre **Construire APK Android**.
5. Appuie sur **Run workflow**.
6. Attends la fin du workflow.
7. Ouvre l'exécution réussie et télécharge l'artefact `Jules-Enock-Lesteke-Jwet-Mab-APK`.
8. Décompresse-le et installe `app-debug.apk` sur Android.

## Note
L'APK produit est une version Debug, adaptée aux tests et à l'installation personnelle. Une publication Google Play demandera ensuite une signature Release.
